A browser-based tool for previewing content mapped onto a fulldome cinema surface. The 3D model is based on [Wisdome Stockholm](https://wisdome.se). Drop in an image or video and see how it looks projected. Built with Three.js for the [Dome Dreaming](https://www.domedreaming.com) project.
