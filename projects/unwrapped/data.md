A lightweight UV inspection tool built with Three.js. Drop in a 3D model (.glb, .gltf, .obj, .fbx) and preview its UV layout with checker grids, colour gradients, or your own textures. Useful for catching seams, checking texel density, and testing materials before committing to a render pipeline.

[Try it](https://jonasjohansson.github.io/unwrapped/) · [GitHub](https://github.com/jonasjohansson/unwrapped)
