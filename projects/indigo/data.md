A set of native macOS tools for routing video between NDI, Syphon, and the web.

**Indigo** takes any URL and outputs it as a Syphon or NDI video stream at up to 4K. You can interact with the page while broadcasting, inject custom CSS to restyle it, and it captures audio over NDI too.

[GitHub](https://github.com/jonasjohansson/Indigo) · [Download v1.0](https://github.com/jonasjohansson/Indigo/releases/tag/v1.0)

**Indigo3** is an NDI/Syphon to WebSocket H.265 bridge, streaming video sources to the browser in real time.

[GitHub](https://github.com/jonasjohansson/indigo3) · [Download v1.0](https://github.com/jonasjohansson/indigo3/releases/tag/v1.0.0)
