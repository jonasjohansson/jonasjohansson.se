A native macOS app for feeding web content into Resolume and other VJ software. It takes any URL and outputs it as a Syphon or NDI video stream at up to 4K. You can interact with the page while broadcasting, inject custom CSS to restyle it, and it captures audio over NDI too. Built with Objective-C, Metal, and ScreenCaptureKit.
