A set of tiny browser tools I keep around for quick lookups and prototyping. Nothing fancy, just things I got tired of googling.

- [Color Picker](https://jonasjohansson.github.io/helpers/colorpicker) — pick and copy color values
- [Color Table](https://jonasjohansson.github.io/helpers/colortable) — named CSS colors at a glance
- [Emoji](https://jonasjohansson.github.io/helpers/emoji) — searchable emoji reference
- [Favicon](https://jonasjohansson.github.io/helpers/favicon) — animated favicon from a sprite sheet
- [Images](https://jonasjohansson.github.io/helpers/images) — generate solid color images at any size
- [Keycode](https://jonasjohansson.github.io/helpers/keycode) — press a key, get the code
- [Resistor Values](https://jonasjohansson.github.io/helpers/resistorvalues) — resistor color band calculator
- [Ruler](https://jonasjohansson.github.io/helpers/ruler) — on-screen ruler in pixels, mm, or inches
- [Timer](https://jonasjohansson.github.io/helpers/timer) — simple click-to-start timer
- [UI Avatar](https://jonasjohansson.github.io/helpers/ui-avatar) — generate initial-based avatars
